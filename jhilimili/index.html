Jhilimili

Explore colors. Experiment with light. Have fun.

Jhilimili is a keyboard-controlled color playground. Change your screen background using alphabet shortcuts, CSS color names, and special commands.

01. Alphabet Color Shortcuts

Press any letter from A to Z to cycle through its assigned color palette. Repeated presses move to the next color.

02. Type Color Names

Type any valid CSS named color to apply it directly. Examples:

  • Red
  • DarkSlateBlue
  • MediumVioletRed
  • RebeccaPurple
  • LightGoldenRodYellow

03. Special Commands

  • show – Display the current color name at the top-right.
  • hide – Hide the color name.
  • info – Open this information window.
  • jhilimili – Start the random disco effect.
  • stop – Stop disco and keep the current color.

04. Disco Mode

Type jhilimili to continuously display randomly selected CSS colors.

While disco is running, press:

  • 1 – Slowest speed
  • 2 to 8 – Increasing speed
  • 9 – Fastest speed

05. Reset

Press Esc to stop disco, reset the background to white, and clear the current command.

Press any key or click outside this window to close.
